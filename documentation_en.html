Chapter 03

Project Introduction & Philosophy

The Problem: Bloated Web SOCs vs. Fragile CLI Scripts

In modern cybersecurity operations, security analysts and network administrators are caught between two extremes:

  1. Overweight Enterprise SIEMs: Platforms like Splunk, Elastic, or cloud-managed XDR suites demand gigabytes of RAM, complex distributed agents, mandatory web browsers, external cloud subscriptions, and continuous telemetry exfiltration. They are completely unsuited for rapid local field audits, home laboratories, isolated incident response, or air-gapped forensic environments.
  2. Fragmented CLI Utilities: Standalone tools like nmap, tcpdump, netstat, and arp are fast, but they operate in isolation. They lack unified state persistence, historical correlation, real-time visual dashboards, automated threat scoring, and structured report exports.

The COWMAN Vision

COWMAN was built to occupy the sweet spot: a zero-cloud, local-first Security Operations Center (SOC) running entirely within a single terminal window.

Written in modern Python 3.12+, COWMAN marries the speed and ergonomics of a native command-line interface with the architectural rigor of an enterprise SIEM. It executes authorized network discovery, correlates open ports with vulnerability profiles, monitors live throughput and socket-to-process attribution, computes real-time Shannon entropy over intercepted DNS queries, persists all audit trails into an embedded SQLite database, and reconstructs live network topology diagrams on demand.

Chapter 04

Project Goals & Operational Use Cases

Core Engineering Goals

Goal 1

100% Local-First Privacy

Zero telemetry, cloud beacons, or external dependencies. All device metadata, DNS queries, and security events remain strictly inside the local SQLite database.

Goal 2

Strictly Defensive Telemetry

Zero exploit payloads, credential brute-forcing, or evasive evasion logic. COWMAN is built exclusively for authorized auditing, inventory, and intrusion detection.

Goal 3

Resilient Multi-Stage Fallbacks

Gracefully degrades across operating systems and privilege levels. If raw Scapy packet capture is unavailable, it automatically falls back to system ARP tables and TCP connect sweeps.

Goal 4

High Concurrency & Low Latency

Combines non-blocking asyncio socket pools with background threading sniffers to maintain full terminal responsiveness under heavy network traffic.

Practical Operational Use Cases

  • Air-Gapped & SCADA/ICS Audits: Conducting rapid security audits in isolated control rooms where internet access is physically prohibited.
  • Rogue Device Detection: Instantly alerting analysts when an unknown MAC address (e.g. unauthorized laptop, Raspberry Pi, rogue Wi-Fi pineapple) connects to the subnet.
  • Legacy Protocol Discovery: Identifying plaintext, unencrypted administrative protocols (Telnet, FTP, unencrypted HTTP) violating compliance standards.
  • Covert DNS Tunneling & DGA Hunting: Sniffing port 53 traffic to catch malware data exfiltration and domain generation algorithms using mathematical Shannon entropy.
  • Incident Post-Mortem & Timeline Replay: Replaying historical security events chronologically at variable speeds to reconstruct incident escalation sequences.
  • Automated Compliance Reporting: Exporting comprehensive network audit inventories to Markdown, JSON, and CSV for executive reporting and SIEM ingestion.

Complete Project Architecture

COWMAN is built following Clean Architecture and Hexagonal (Ports and Adapters) principles. The system is strictly partitioned into six decoupled layers with unidirectional inward dependency flows:

Figure 5.1: COWMAN Layered Architecture Blueprint

Architectural Boundaries & Data Invariants

  • 1. Presentation Layer (CLI & UI): Uses Typer for declarative command routing and Rich for live terminal rendering. Contains zero network socket calls or direct SQL queries.
  • 2. Telemetry & Network Layer: Interacts with the OS kernel and network sockets (psutil, Scapy, asyncio). Converts raw bytes and OS tables into validated Pydantic models.
  • 3. Defensive Security Engine: Pure business logic. Receives telemetry models, evaluates security rules, computes entropy heuristics, and emits typed SecurityEvents.
  • 4. Storage & Persistence Layer: Manages local SQLite persistence using SQLAlchemy ORMs and the Repository pattern. Runs with Write-Ahead Logging (WAL) for safe multi-threaded concurrency.
  • 5. Core Foundation: Shared Pydantic domain models, TOML configuration loader, and structured logging. Has zero dependencies on upper layers.
  • 6. Utility Subsystem: Cross-platform OS detection, flexible time parsers, and multi-format exporters (Markdown, JSON, CSV).

Chapter 09

Complete Program Flow from Startup to Shutdown

Six Discrete Execution Phases

From initial shell invocation to process exit, COWMAN transitions through 6 deterministic phases:

  1. Phase 1: Shell Bootstrap: The OS executes the cowman binary stub generated by pip, transferring execution to src/cowman/main.py:app().
  2. Phase 2: CLI Parsing & Eager Flags: Typer parses sys.argv. If --version is supplied, it executes immediately and exits. Otherwise, it prepares argument dispatch.
  3. Phase 3: Core Initialization: load_config() parses config.toml, setup_logger() sets up Rich logging, and init_db() verifies the SQLite schema and WAL mode.
  4. Phase 4: Dispatch & Execution: The selected subcommand or interactive SOC menu is executed. Network tasks run via asyncio.run(); packet sniffers start daemon threads.
  5. Phase 5: Signal Interruption: Upon receiving Ctrl+C (SIGINT), active loops catch KeyboardInterrupt, stop daemon threads, join worker pools, and drain sockets.
  6. Phase 6: Terminal Restoration & Clean Exit: Rich console states are restored, SQLite connections are closed, and an appropriate exit code (0, 1, or 130) is returned.

Detailed Explanation of Every Function and Method

Core Subsystem Function Catalog

  • calculate_subnet(ip: str, netmask: str) -> IPv4Network: Derives the IPv4 subnet object from local IP and netmask. Strictly caps sweeps to /24 maximum to prevent runaway scans on large networks.
  • calculate_entropy(text: str) -> float: Calculates Shannon entropy in bits per symbol for a domain string using character frequency distribution. Used to detect algorithmic DGAs.
  • lookup_vendor(mac_address: str) -> str: Resolves the hardware manufacturer from the first 3 octets using the built-in 100% offline IEEE OUI dictionary.
  • parse_datetime_flexible(val: str) -> datetime: Parses ISO timestamps, times (HH:MM:SS), dates, or relative duration strings (e.g. '1h', '30m', '2d').
  • get_default_gateway_and_interface() -> tuple[Optional[str], Optional[str]]: Resolves the default gateway IP and the active network adapter using Scapy routing tables or OS fallbacks.
  • parse_arp_table() -> dict[str, str]: Parses operating system ARP tables ('arp -a' on Windows, 'arp -an' on Linux/macOS) into IP-to-MAC mappings for zero-privilege discovery.
  • sweep_subnet(network, concurrency) -> None: Asynchronously probes candidate hosts using brief TCP connects to populate the OS kernel ARP cache.
  • inspect_dns_anomaly(query_name, config) -> tuple[bool, str]: Heuristic engine checking domain length, Shannon entropy, and hex/base64 subdomain prefixes.
  • init_db(custom_path=None) -> None: Generates all relational database tables and configures SQLite PRAGMA journal_mode=WAL.

Chapter 16

Error Handling & Robustness

Resilience Mechanisms

  • Unprivileged Execution: If raw socket access fails on Windows/Linux, Scapy errors are caught and COWMAN automatically falls back to system ARP tables and TCP connect sweeps.
  • Socket Timeouts: All network socket calls use strict timeouts (0.8s default) with asyncio.wait_for(), preventing hangs on filtered ports.
  • Database Concurrency: SQLite operates with check_same_thread=False and automatic transaction rollback on exceptions.
  • Terminal Unicode Fallbacks: On Windows consoles using legacy code pages, stdout is automatically reconfigured to UTF-8 with error replacement to prevent UnicodeEncodeError.
  • Subnet Safety Clamping: Subnet calculations are strictly bounded to a maximum of /24 (254 addresses) to protect enterprise subnets from unintended flooding.

Security Considerations & Defensive Model

Ethical Scanning Mandate
COWMAN is built solely for authorized defensive audits. Never probe networks without explicit permission.

Defensive Hardening Safeguards:

  • Terminal Injection Defense: Banner grabbing routines explicitly sanitize returned strings, stripping ANSI escape sequences and non-printable bytes to prevent terminal exploitation.
  • Zero Intrusive Payloads: Port scanning uses standard TCP three-way handshakes without malicious exploit triggers or fuzzing payloads.
  • Local-First Telemetry: No device IP, MAC address, hostname, or captured DNS query is ever transmitted outside the host machine.

Programmatic API Examples & Walkthroughs

Python API Example: Custom Discovery & Audit Script
import asyncio
from cowman.network.scanner import NetworkScanner
from cowman.network.ports import PortAnalyzer

async def custom_audit():
    # 1. Discover devices on local subnet
    scanner = NetworkScanner()
    devices = await scanner.discover()
    print(f"Discovered {len(devices)} active devices.")

    # 2. Audit open ports on discovered devices
    for d in devices:
        if d.status == "ONLINE":
            analyzer = PortAnalyzer(target_host=d.ip, ports=[80, 443, 22, 23, 445])
            report = await analyzer.scan()
            print(f"Host {d.ip} ({d.vendor}): {len(report.open_ports)} open ports.")

asyncio.run(custom_audit())

Symptom: Scapy raises Npcap warning or packet sniffing fails.
Remedy: Install Npcap from npcap.com with WinPcap API compatibility mode checked.

def parse_port_list(port_spec: Optional[str]) -> Optional[List[int]]:
    """Parse port arguments like '80,443,8080' or '20-25' into a list of integers."""
    if not port_spec:
        return None

    ports: List[int] = []
    for part in port_spec.split(","):
        part = part.strip()
        if "-" in part:
            try:
                start_p, end_p = map(int, part.split("-"))
                ports.extend(range(max(1, start_p), min(65535, end_p) + 1))
            except ValueError:
                continue
        elif part.isdigit():
            p = int(part)
            if 1 <= p <= 65535:
                ports.append(p)

    return sorted(list(set(ports))) if ports else None

def get_default_gateway_and_interface() -> Tuple[Optional[str], Optional[str]]:
    """Determine default gateway IP and the associated network interface name."""
    # Method 1: Try Scapy routing table if available
    try:
        from scapy.all import conf
        # conf.route.route("8.8.8.8") returns (interface, output_ip, gateway_ip)
        res = conf.route.route("8.8.8.8")
        if res and len(res) >= 3:
            iface_name = res[0]
            gateway_ip = res[2]
            if gateway_ip and gateway_ip != "0.0.0.0":
                return gateway_ip, iface_name
    except Exception:
        pass

    # Method 2: System socket connection check to find local route
    chosen_iface = None
    local_ip = None
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        s.settimeout(0.5)
        s.connect(("8.8.8.8", 53))
        local_ip = s.getsockname()[0]
        s.close()
    except Exception:
        pass

    if local_ip:
        # Match local_ip to interface
        for name, addrs in psutil.net_if_addrs().items():
            for addr in addrs:
                if addr.family == socket.AF_INET and addr.address == local_ip:
                    chosen_iface = name
                    break
            if chosen_iface:
                break

    # Method 3: OS command fallback for gateway
    gateway = None
    if is_windows():
        try:
            output = subprocess.check_output("netsh interface ip show config", shell=True, text=True, stderr=subprocess.DEVNULL)
            for line in output.splitlines():
                if "Default Gateway" in line or "기본 게이트웨이" in line or "デフォルト ゲートウェイ" in line:
                    parts = line.split(":")
                    if len(parts) >= 2:
                        gw = parts[1].strip()
                        if gw and gw != "0.0.0.0":
                            gateway = gw
                            break
        except Exception:
            pass
    elif is_linux():
        try:
            with open("/proc/net/route") as f:
                for line in f.readlines()[1:]:
                    fields = line.strip().split()
                    if fields[1] == "00000000":
                        # Destination is 0.0.0.0 (default)
                        gw_hex = fields[2]
                        gateway = socket.inet_ntoa(bytes.fromhex(gw_hex)[::-1])
                        if not chosen_iface:
                            chosen_iface = fields[0]
                        break
        except Exception:
            pass

    return gateway, chosen_iface


def get_dns_servers() -> List[str]:
    """Retrieve active system DNS servers."""
    servers: List[str] = []

    # Try Scapy conf nameservers
    try:
        from scapy.all import conf
        for ns in conf.nameservers:
            if ns and ns not in servers and ns != "0.0.0.0":
                servers.append(str(ns))
    except Exception:
        pass

    if servers:
        return servers

    if is_linux() or is_macos():
        try:
            with open("/etc/resolv.conf", "r") as f:
                for line in f:
                    line = line.strip()
                    if line.startswith("nameserver"):
                        parts = line.split()
                        if len(parts) >= 2 and parts[1] not in servers:
                            servers.append(parts[1])
        except Exception:
            pass
    elif is_windows():
        try:
            output = subprocess.check_output("ipconfig /all", shell=True, text=True, stderr=subprocess.DEVNULL)
            for line in output.splitlines():
                if "DNS Servers" in line or "DNS 서버" in line:
                    parts = line.split(":")
                    if len(parts) >= 2:
                        ip = parts[1].strip()
                        if ip and ip not in servers and not ip.startswith("fe80"):
                            servers.append(ip)
        except Exception:
            pass

    return servers


def get_all_interfaces() -> List[NetworkInterface]:
    """Retrieve full details of all system network interfaces."""
    addrs = psutil.net_if_addrs()
    stats = psutil.net_if_stats()
    io_counters = psutil.net_io_counters(pernic=True)

    results: List[NetworkInterface] = []

    for name, addr_list in addrs.items():
        ip = None
        netmask = None
        broadcast = None
        mac = None

        for a in addr_list:
            # IPv4
            if a.family == socket.AF_INET:
                ip = a.address
                netmask = a.netmask
                broadcast = a.broadcast
            # MAC Address
            elif (
                (hasattr(psutil, "AF_LINK") and a.family == psutil.AF_LINK)
                or (is_windows() and getattr(a, "family", None) == -1)
                or ("link" in str(getattr(a, "family", "")).lower())
            ):
                if a.address and len(a.address) in (12, 17):
                    mac = a.address

        st = stats.get(name)
        is_up = st.isup if st else False
        speed = st.speed if st else 0
        mtu = st.mtu if st else 1500

        io = io_counters.get(name)
        rx_b = io.bytes_recv if io else 0
        tx_b = io.bytes_sent if io else 0
        rx_p = io.packets_recv if io else 0
        tx_p = io.packets_sent if io else 0

        results.append(
            NetworkInterface(
                name=name,
                ip=ip,
                netmask=netmask,
                broadcast=broadcast,
                mac=mac,
                is_up=is_up,
                speed_mbps=speed,
                mtu=mtu,
                rx_bytes=rx_b,
                tx_bytes=tx_b,
                rx_packets=rx_p,
                tx_packets=tx_p,
            )
        )

    # Sort UP interfaces with IPs first
    results.sort(key=lambda x: (not x.is_up, x.ip is None, x.name))
    return results


def get_primary_interface() -> Optional[NetworkInterface]:
    """Get the primary active network interface connected to the network."""
    interfaces = get_all_interfaces()
    gateway, gw_iface = get_default_gateway_and_interface()

    # Try matching gw_iface
    if gw_iface:
        for iface in interfaces:
            if iface.name == gw_iface or (iface.ip and gw_iface == iface.ip):
                return iface

    # Otherwise find first UP interface with non-loopback IPv4
    for iface in interfaces:
        if iface.is_up and iface.ip and not iface.ip.startswith("127."):
            return iface

    return interfaces[0] if interfaces else None


def get_system_network_overview() -> SystemNetworkOverview:
    """Build unified system overview for CLI display and reports."""
    primary = get_primary_interface()
    gateway, _ = get_default_gateway_and_interface()
    dns = get_dns_servers()

    try:
        conns = len(psutil.net_connections(kind="inet"))

def calculate_subnet(ip: str, netmask: Optional[str]) -> ipaddress.IPv4Network:
    """Calculate IPv4 network from IP and netmask, capped at /24 for safe local scanning."""
    if not netmask or netmask in ["0.0.0.0", "255.255.255.255"]:
        netmask = "255.255.255.0"
    try:
        network = ipaddress.IPv4Network(f"{ip}/{netmask}", strict=False)
        # Prevent accidentally scanning large /8 or /16 networks by bounding to /24
        if network.prefixlen < 24:
            ip_obj = ipaddress.IPv4Address(ip)
            c_block = f"{ip_obj.exploded.rsplit('.', 1)[0]}.0/24"
            return ipaddress.IPv4Network(c_block, strict=False)
        return network
    except Exception:
        ip_parts = ip.split(".")
        return ipaddress.IPv4Network(f"{ip_parts[0]}.{ip_parts[1]}.{ip_parts[2]}.0/24", strict=False)


def parse_arp_table() -> Dict[str, str]:
    """Parse operating system ARP table into {ip: mac} dictionary."""
    arp_entries: Dict[str, str] = {}
    try:
        if is_windows():
            output = subprocess.check_output("arp -a", shell=True, text=True, stderr=subprocess.DEVNULL)
            # Lines like: 192.168.1.1   00-11-22-33-44-55   dynamic
            pattern = re.compile(r"([0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3})\s+([0-9a-fA-F\-]{17})\s+([a-zA-Z]+)")
            for match in pattern.finditer(output):
                ip_str = match.group(1)
                mac_str = match.group(2).replace("-", ":")
                entry_type = match.group(3).lower()
                if not ip_str.endswith(".255") and not ip_str.startswith("224.") and entry_type != "invalid":
                    arp_entries[ip_str] = normalize_mac(mac_str)
        else:
            # Linux / macOS
            try:
                output = subprocess.check_output("arp -an", shell=True, text=True, stderr=subprocess.DEVNULL)
                pattern = re.compile(r"\(([0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3})\)\s+at\s+([0-9a-fA-F:]{17})")
                for match in pattern.finditer(output):
                    ip_str = match.group(1)
                    mac_str = match.group(2)
                    arp_entries[ip_str] = normalize_mac(mac_str)
            except Exception:
                pass
    except Exception as e:
        logger.debug(f"Failed to read system ARP table: {e}")

    return arp_entries

        name_info = await loop.run_in_executor(None, socket.getnameinfo, (ip, 0), socket.NI_NAMEREQD)

        pass

    try:
        host, _, _ = await loop.run_in_executor(None, socket.gethostbyaddr, ip)
        if host and host != ip:
            return host
    except Exception:
        pass

    return None

def scan_scapy_arp(network_cidr: str, iface: Optional[str] = None, timeout: float = 1.5) -> Dict[str, str]:
    """Execute Scapy ARP broadcast ping if supported and permitted."""

def calculate_entropy(text: str) -> float:
    """Calculate Shannon entropy for string randomness detection (DGA indicator)."""
    if not text:
        return 0.0
    text = text.lower()
    freq = {}
    for c in text:
        freq[c] = freq.get(c, 0) + 1
    length = len(text)
    entropy = 0.0
    for count in freq.values():
        p = count / length
        entropy -= p * math.log2(p)
    return round(entropy, 3)


def inspect_dns_anomaly(query_name: str, config=None) -> tuple[bool, Optional[str]]:
    """Evaluate whether a DNS query matches known anomaly patterns."""
    cfg = config or get_config()
    clean_domain = query_name.rstrip(".")

    # High length check (indicative of DNS tunneling or data exfiltration)
    if len(clean_domain) > cfg.dns.domain_length_alert_threshold:
        return True, f"Excessive domain length ({len(clean_domain)} chars) - potential DNS tunnel"

    # Entropy check for base domain labels
    labels = clean_domain.split(".")
    for label in labels:
        if len(label) > 10:
            ent = calculate_entropy(label)
            if ent > cfg.dns.entropy_alert_threshold:
                return True, f"High Shannon entropy ({ent:.2f}) on label '{label}' - potential DGA"

    # Suspicious hex or base64 encoded subdomain
    if len(labels) > 0 and len(labels[0]) > 20:
        if all(c in "0123456789abcdef" for c in labels[0].lower()):
            return True, "Hex-encoded subdomain prefix - potential tunneling"

    return False, None


class DnsMonitor:
    """Captures and analyzes DNS network traffic."""

    def __init__(self, interface: Optional[str] = None):
        self.config = get_config()
        self.interface_name = interface or self.config.general.interface
        self._packet_queue: queue.Queue = queue.Queue(maxsize=self.config.dns.buffer_size)
        self._stop_event = threading.Event()
        self._sniffer_thread: Optional[threading.Thread] = None

    def _process_packet(self, pkt):
        try:
            if pkt.haslayer(scapy.DNS) and pkt.getlayer(scapy.DNS).qr == 0:  # qr == 0 is DNS Query
                dns_layer = pkt.getlayer(scapy.DNS)
                if dns_layer.qd is None:
                    return

                qname = dns_layer.qd.qname.decode("utf-8", errors="ignore").rstrip(".")
                qtype_code = dns_layer.qd.qtype
                qtype_str = DNS_QTYPE_MAP.get(qtype_code, str(qtype_code))

                src_ip = "Unknown"
                dst_ip = "Unknown"

                if pkt.haslayer(scapy.IP):
                    src_ip = pkt[scapy.IP].src
                    dst_ip = pkt[scapy.IP].dst
                elif pkt.haslayer(scapy.IPv6):
                    src_ip = pkt[scapy.IPv6].src
                    dst_ip = pkt[scapy.IPv6].dst

                is_anomaly, reason = inspect_dns_anomaly(qname, self.config)

                event = DnsQueryEvent(
                    timestamp=utc_now(),
                    source_ip=src_ip,
                    destination_ip=dst_ip,
                    query_name=qname,
                    query_type=qtype_str,
                    is_anomalous=is_anomaly,
                    anomaly_reason=reason,
                )

                # Persist to database
                DnsLogRepository.log(event)

                try:
                    self._packet_queue.put_nowait(event)
                except queue.Full:
                    try:
                        self._packet_queue.get_nowait()
                        self._packet_queue.put_nowait(event)
                    except Exception:
                        pass
        except Exception as e:
            logger.debug(f"Error parsing DNS packet: {e}")

    def _sniff_worker(self):
        kwargs = {
            "filter": "udp port 53 or tcp port 53",
            "prn": self._process_packet,
            "store": 0,
            "stop_filter": lambda _: self._stop_event.is_set(),
        }
        if self.interface_name:
            kwargs["iface"] = self.interface_name

        try:
            scapy.sniff(**kwargs)
        except Exception as e:
            logger.warning(f"DNS sniffer stopped: {e}")

    def start(self) -> bool:
        """Start sniffer background thread. Returns False if unprivileged."""
        self._stop_event.clear()
        self._sniffer_thread = threading.Thread(target=self._sniff_worker, daemon=True)
        self._sniffer_thread.start()
        return True

    def stop(self):
        """Stop sniffer thread."""
        self._stop_event.set()
        if self._sniffer_thread and self._sniffer_thread.is_alive():
            self._sniffer_thread.join(timeout=1.0)

    def get_events(self, timeout: float = 0.5) -> List[DnsQueryEvent]:
        """Drain buffered events from sniffer queue."""
        events: List[DnsQueryEvent] = []
        try:
            while not self._packet_queue.empty():
                events.append(self._packet_queue.get_nowait())
        except Exception:
            pass
        return events

    """Central engine managing defensive security detection rules."""

    def __init__(self):
        self.rules: List[BaseSecurityRule] = [
            NewDeviceRule(),
            DeviceStateChangeRule(),
            UnexpectedServiceRule(),
            InterfaceStateRule(),
            DnsAnomalyRule(),
            NetworkAnomalyRule(),
        ]
        self._listeners: List[Callable[[SecurityEvent], None]] = []

    def register_rule(self, rule: BaseSecurityRule) -> None:
        """Add a custom detection rule to the engine."""
        self.rules.append(rule)

    def subscribe(self, callback: Callable[[SecurityEvent], None]) -> None:
        """Register a callback for newly triggered security events."""
        self._listeners.append(callback)

    def evaluate(self, context: Dict[str, Any]) -> List[SecurityEvent]:
        """Run all active rules against the telemetry context, saving events to DB."""
        new_events: List[SecurityEvent] = []

        for rule in self.rules:
            try:
                matched = rule.evaluate(context)
                for event in matched:
                    # Persist event to database
                    saved_event = SecurityEventRepository.add(event)
                    new_events.append(saved_event)
                    logger.info(f"[{event.severity.value}] {event.title}: {event.description}")
                    # Notify registered listeners
                    for listener in self._listeners:
                        try:
                            listener(saved_event)
                        except Exception as e:
                            logger.debug(f"Error in event listener: {e}")
            except Exception as e:
                logger.error(f"Rule evaluation failed for {rule.rule_id}: {e}")

        return new_events

    def process_device_discovery(self, device: Device, is_new: bool = False, old_status: Optional[str] = None) -> List[SecurityEvent]:

        ctx = {

                    existing.open_ports = merged_ports

                meta.update(device.metadata)
                existing.metadata_dict = meta

                    metadata_dict=device.metadata or {},
                )
                s.add(new_model)
                s.flush()

import re

def parse_datetime_flexible(value: Optional[str]) -> Optional[datetime]:
    """Parse a date/time string, ISO timestamp, or relative time offset (e.g. '1h', '30m', '1d')."""
    if not value or not value.strip():
        return None

    val = value.strip().lower()
    now = datetime.now(timezone.utc)

    # Relative offset: e.g. "15m", "2h", "1d", "7d", "30s"
    rel_match = re.match(r"^(\d+)\s*(s|sec|m|min|h|hr|d|day|w|week)s?$", val)
    if rel_match:
        amount = int(rel_match.group(1))
        unit = rel_match.group(2)
        if unit.startswith("s"):
            return now - timedelta(seconds=amount)
        elif unit.startswith("m"):
            return now - timedelta(minutes=amount)
        elif unit.startswith("h"):
            return now - timedelta(hours=amount)
        elif unit.startswith("d"):
            return now - timedelta(days=amount)
        elif unit.startswith("w"):
            return now - timedelta(weeks=amount)

    if val == "today":
        return now.replace(hour=0, minute=0, second=0, microsecond=0)
    elif val == "yesterday":
        yesterday = now - timedelta(days=1)
        return yesterday.replace(hour=0, minute=0, second=0, microsecond=0)

    # Try common formats
    formats = [
        "%Y-%m-%dT%H:%M:%S%z",
        "%Y-%m-%dT%H:%M:%S",
        "%Y-%m-%d %H:%M:%S",
        "%Y-%m-%d %H:%M",
        "%Y-%m-%d",
        "%H:%M:%S",
        "%H:%M",
    ]

    for fmt in formats:
        try:
            parsed = datetime.strptime(value.strip(), fmt)
            if fmt in ["%H:%M:%S", "%H:%M"]:
                # Combine with today's date
                parsed = now.replace(
                    hour=parsed.hour,
                    minute=parsed.minute,
                    second=parsed.second,
                    microsecond=0,
                )
            if parsed.tzinfo is None:
                parsed = parsed.replace(tzinfo=timezone.utc)
            return parsed
        except ValueError:
            continue

    raise ValueError(f"Unable to parse timestamp or relative time '{value}'. Examples: '1h', '30m', '2026-09-30 14:00'.")


def format_timestamp(dt: Optional[datetime] = None, include_date: bool = True) -> str:
    """Format datetime cleanly for terminal display. Defaults to current time if None."""
    if dt is None:
        dt = datetime.now(timezone.utc)
    local_dt = dt.astimezone() if dt.tzinfo else dt
    if include_date:
        return local_dt.strftime("%Y-%m-%d %H:%M:%S")
    return local_dt.strftime("%H:%M:%S")


def format_duration(seconds: float) -> str:
    """Format duration in seconds to human-readable string."""
    if seconds < 1.0:
        return f"{seconds * 1000:.1f}ms"
    elif seconds < 60:
        return f"{seconds:.2f}s"
    elif seconds < 3600:
        mins = int(seconds // 60)
        secs = int(seconds % 60)
        return f"{mins}m {secs}s"
    else:
        hours = int(seconds // 3600)
        mins = int((seconds % 3600) // 60)
        return f"{hours}h {mins}m"
