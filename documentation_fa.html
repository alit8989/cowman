چالش اساسی: سامانه‌های وب‌محور سنگین در برابر اسکریپت‌های متفرقه

در اکوسیستم کنونی امنیت شبکه و پایش تله‌متری، کارشناسان امنیت سایبری معمولاً میان دو رویکرد متضاد گرفتار می‌شوند:

  1. سامانه‌های مدیریت رویداد و امنیت (SIEM) سنگین: راهکارهایی مانند Splunk، Elastic یا بسته‌های XDR ابری نیازمند گیگابایت‌ها حافظه رم، ایجنت‌های توزیع‌شده پیچیده، مرورگرهای وب سنگین، اشتراک‌های مالی مداوم و ارسال ترافیک به سرورهای خارجی هستند. این ابزارها برای ممیزی‌های سریع میدانی، آزمایشگاه‌های خانگی، پاسخ سریع به حوادث و محیط‌های کاملاً ایزوله (Air-Gapped) غیرقابل استفاده یا بسیار ناکارآمدند.
  2. ابزارهای پراکنده ترمینال: دستوراتی چون nmap، tcpdump، netstat و arp هرچند سریع هستند، اما به‌صورت جزیره‌ای عمل می‌کنند. آن‌ها فاقد پایگاه داده متمرکز، همبسته‌سازی تاریخی وقایع، داشبورد زنده گرافیکی در پایانه، امتیازدهی خودکار به تهدیدات و امکان استخراج گزارش‌های مدیریتی جامع هستند.

چشم‌انداز و مأموریت COWMAN

پلتفرم COWMAN دقیقاً در نقطه تعادل بهینه طراحی شده است: یک مرکز عملیات امنیت (SOC) کاملاً محلی و بدون وابستگی به ابر که صددرصد در یک پنجره ترمینال اجرا می‌شود.

این سامانه با بهره‌گیری از پایتون نسخه ۳.۱۲+، زیبایی بصری و کارایی ارگونومیک پایانه خط فرمان را با دقت معماری ابزارهای پیشرفته سازمانی پیوند می‌زند. COWMAN مجهز به قابلیت کشف مجاز تجهیزات شبکه، انطباق پورت‌ها با آسیب‌پذیری‌های متداول، پایش لحظه‌ای مصرف ترافیک و انتساب سوکت‌ها به پروسه‌های محلی، محاسبه بلادرنگ آنتروپی شانون در پرس‌وجوهای DNS، ثبت دائمی تمامی داده‌ها در دیتابیس محلی SQLite و بازسازی پویای ساختار درختی شبکه است.

سناریوهای عملیاتی در دنیای واقعی

  • محیط‌های صنعتی و ایزوله (SCADA/ICS): ارزیابی فوری شبکه‌های صنعتی که به دلایل امنیتی فاقد هرگونه دسترسی به اینترنت هستند.
  • کشف تجهیزات ناشناس (Rogue Devices): اعلام هشدار آنی در لحظه اتصال یک لپ‌تاپ ناآشنا، مینی‌کامپیوتر رزبری‌پای یا روتر بی‌سیم غیرمجاز به زیرشبکه.
  • پالایش پروتکل‌های ناامن متنی: شناسایی پورت‌های باز با پروتکل‌های قدیمی و فاقد رمزنگاری (مانند Telnet، FTP و HTTP بدون SSL).
  • کشف کانال‌های نشت داده بر بستر DNS: مانیتورینگ پرس‌وجوهای ارسالی روی پورت ۵۳ و کشف بدافزارها بر اساس شاخص آماری آنتروپی شانون.
  • کالبدشکافی حوادث و بازپخش زمانی: امکان بازپخش منظم رویدادهای امنیتی با سرعت‌های مختلف جهت مستندسازی دقیق زنجیره حمله.
  • تولید گزارش‌های رسمی انطباق: استخراج خودکار شناسنامه شبکه در فرمت‌های مارک‌داون، جیسون و CSV جهت ارائه به مراجع نظارتی.

معماری جامع سامانه و الگوهای مهندسی نرم‌افزار

طراحی سامانه COWMAN بر پایه الگوهای Clean Architecture و معماری شش‌ضلعی (Ports & Adapters) استوار است. این ساختار تفکیک‌شده متضمن جهت‌گیری یک‌سویه وابستگی‌ها به سمت لایه‌های زیرین و استقلال منطق تجاری از رابط کاربری است:

نمودار ۵.۱: دیاگرام معماری چندلایه‌ای پلتفرم COWMAN

لایه‌های شش‌گانه سامانه و مرزهای تفکیک

  • ۱. لایه نمایش (CLI & UI): شامل کتابخانه Typer برای هدایت فرامین و Rich جهت رندر داشبورد زنده، پنل‌ها و جداول. این لایه عاری از هرگونه تماس مستقیم با سوکت یا کوئری‌های SQL است.
  • ۲. لایه تله‌متری و شبکه: ارتباط مستقیم با هسته سیستم‌عامل و درایورهای شبکه (psutil, Scapy, asyncio). تبدیل خروجی‌های خام سیستم‌عامل به مدل‌های اعتبارسنجی‌شده Pydantic.
  • ۳. موتور امنیتی پدافندی: منطق ناب ممیزی و ارزیابی. دریافت مدل‌های تله‌متری، تطبیق با قوانین امنیتی، محاسبه معیارهای آنتروپی و صدور رویدادهای SecurityEvent.
  • ۴. لایه ذخیره‌سازی و دیتابیس: نگاشت شیء-رابطه‌ای بر پایه SQLAlchemy ۲.۰، پیاده‌سازی الگوی مخزن (Repository) و پیکربندی SQLite در حالت WAL برای هم‌روندی بالا.
  • ۵. هسته بنیادین (Core): مدل‌های دامنه Pydantic، پارسر فایل‌های تنظیمات TOML و پیکربندی سیستم لاگ‌برداری ساختاریافته.
  • ۶. زیرسیستم ابزارهای کمکی (Utils): تشخیص مشخصات سیستم‌عامل، پارسر منعطف زمان و ماژول‌های صدور گزارش چندفرمت.

از لحظه فشردن کلید اینتر در ترمینال تا پایان یافتن پروسه، COWMAN از ۶ گام مشخص عبور می‌کند:

  1. گام ۱: راه‌اندازی در پوسته: سیستم‌عامل فایل اجرایی تولیدشده توسط pip را اجرا کرده و فراخوانی را به main.py:app() منتقل می‌سازد.

  4. گام ۴: اجرای دستور: منطق ناهمگام در حلقه asyncio.run() اجرا می‌شود و در صورت نیاز، ریسه‌های پس‌زمینه شنود شروع به کار می‌نمایند.
  5. گام ۵: مهار سیگنال توقف: در صورت فشردن Ctrl+C، استثنای KeyboardInterrupt با متانت مهار شده و ریسه‌ها به شکلی ایمن پایان می‌پذیرند.
  6. گام ۶: بازنشانی ترمینال و خروج تمیز: پایانه به حالت اولیه بازگشته، نشست‌های دیتابیس بسته شده و کد وضعیت مناسب (۰، ۱ یا ۱۳۰) به پوسته برگردانده می‌شود.

import asyncio
from cowman.network.scanner import NetworkScanner
from cowman.network.ports import PortAnalyzer

async def custom_audit():
    # ۱. کشف تجهیزات در زیرشبکه محلی
    scanner = NetworkScanner()
    devices = await scanner.discover()
    print(f"تعداد {len(devices)} دستگاه فعال در شبکه کشف شد.")

    # ۲. ارزیابی پورت‌های مهم بر روی دستگاه‌های آنلاین
    for d in devices:
        if d.status == "ONLINE":
            analyzer = PortAnalyzer(target_host=d.ip, ports=[80, 443, 22, 23, 445])
            report = await analyzer.scan()
            print(f"میزبان {d.ip} ({d.vendor}): {len(report.open_ports)} پورت باز دارد.")

asyncio.run(custom_audit())

from cowman.security.rules import BaseSecurityRule
from cowman.security.severity import Severity
from cowman.core.models import SecurityEvent

class HighPortCountRule(BaseSecurityRule):
    def __init__(self, threshold: int = 20):
        super().__init__(
            rule_id="RULE-NET-005",
            name="افزایش غیرعادی تعداد پورت‌های باز",
            category="Host Audit",
            default_severity=Severity.MEDIUM,
        )
        self.threshold = threshold

    def evaluate(self, context: dict) -> SecurityEvent | None:
        report = context.get("port_report")
        if report and len(report.open_ports) > self.threshold:
            return SecurityEvent(
                rule_id=self.rule_id,
                title=self.name,
                severity=self.default_severity,
                category=self.category,
                target_ip=report.target_host,
                description=f"میزبان دارای {len(report.open_ports)} پورت باز شناسایی شد.",
            )
        return None

            console.print()

                # Non-interactive fallback (e.g. piped or test environments)
                break

            elif choice == "3":
                target = Prompt.ask("[bold cyan]Target Host / IP to analyze[/bold cyan]", default="127.0.0.1")

                    run_ports(target=target)
            elif choice == "4":
                console.print("[dim]Starting traffic monitor for 10 seconds (or press Ctrl+C)...[/dim]")
                run_monitor(duration=10.0)
            elif choice == "5":
                run_dns(limit=20)
            elif choice == "6":

            break

def parse_port_list(port_spec: Optional[str]) -> Optional[List[int]]:
    """Parse port arguments like '80,443,8080' or '20-25' into a list of integers."""
    if not port_spec:
        return None

    ports: List[int] = []
    for part in port_spec.split(","):
        part = part.strip()
        if "-" in part:
            try:
                start_p, end_p = map(int, part.split("-"))
                ports.extend(range(max(1, start_p), min(65535, end_p) + 1))
            except ValueError:
                continue
        elif part.isdigit():
            p = int(part)
            if 1 <= p <= 65535:
                ports.append(p)

    return sorted(list(set(ports))) if ports else None

def find_config_file(custom_path: Optional[str] = None) -> Optional[Path]:
    """Search for configuration file in precedence order."""
    if custom_path:
        p = Path(custom_path).expanduser().resolve()
        if p.exists() and p.is_file():
            return p
        raise FileNotFoundError(f"Specified configuration file not found: {custom_path}")

    env_path = os.environ.get("COWMAN_CONFIG")
    if env_path:
        p = Path(env_path).expanduser().resolve()
        if p.exists() and p.is_file():
            return p

    local_candidates = [
        Path.cwd() / "cowman.toml",
        Path.cwd() / "config.toml",
        Path.home() / ".cowman" / "config.toml",
        Path.home() / ".config" / "cowman" / "config.toml",
    ]

    for candidate in local_candidates:
        if candidate.exists() and candidate.is_file():
            return candidate

    return None


def load_config(config_path: Optional[str] = None) -> CowmanConfig:
    """Load configuration from file or return standard defaults."""
    global _GLOBAL_CONFIG

    file_to_load = find_config_file(config_path)
    if not file_to_load:
        _GLOBAL_CONFIG = CowmanConfig()
        return _GLOBAL_CONFIG

    try:
        with open(file_to_load, "rb") as f:
            data = tomllib.load(f)
        _GLOBAL_CONFIG = CowmanConfig(**data)
    except Exception as e:
        # Fall back to defaults on parsing error, logging warning
        _GLOBAL_CONFIG = CowmanConfig()

    return _GLOBAL_CONFIG


def get_config() -> CowmanConfig:
    """Get active global configuration or initialize with defaults."""
    global _GLOBAL_CONFIG
    if _GLOBAL_CONFIG is None:
        _GLOBAL_CONFIG = load_config()
    return _GLOBAL_CONFIG

import logging
import sys
from typing import Optional

def setup_logger(level_name: str = "INFO", log_file: Optional[str] = None) -> logging.Logger:
    """Configure and return the root COWMAN logger with Rich formatting."""
    global _LOGGER_INITIALIZED

    level = getattr(logging, level_name.upper(), logging.INFO)
    logger = logging.getLogger("cowman")

    if not _LOGGER_INITIALIZED:
        logger.setLevel(level)
        logger.handlers.clear()

        # Rich console handler for pretty terminal output
        console_handler = RichHandler(
            rich_tracebacks=True,
            show_time=True,
            show_level=True,
            show_path=False,
            tracebacks_suppress=[sys],
            markup=True,
        )
        console_handler.setLevel(level)
        logger.addHandler(console_handler)

        if log_file:
            try:
                file_handler = logging.FileHandler(log_file, encoding="utf-8")
                file_handler.setLevel(level)
                file_format = logging.Formatter(
                    "%(asctime)s [%(levelname)s] %(name)s: %(message)s",
                    datefmt="%Y-%m-%d %H:%M:%S",
                )
                file_handler.setFormatter(file_format)
                logger.addHandler(file_handler)
            except Exception:
                pass  # Fall back to console only if file cannot be opened

        logger.propagate = False
        _LOGGER_INITIALIZED = True
    else:
        logger.setLevel(level)
        for h in logger.handlers:
            h.setLevel(level)

    return logger

    """Retrieve a child logger under the cowman hierarchy."""

def get_default_gateway_and_interface() -> Tuple[Optional[str], Optional[str]]:
    """Determine default gateway IP and the associated network interface name."""
    # Method 1: Try Scapy routing table if available
    try:
        from scapy.all import conf
        # conf.route.route("8.8.8.8") returns (interface, output_ip, gateway_ip)
        res = conf.route.route("8.8.8.8")
        if res and len(res) >= 3:
            iface_name = res[0]
            gateway_ip = res[2]
            if gateway_ip and gateway_ip != "0.0.0.0":
                return gateway_ip, iface_name
    except Exception:
        pass

    # Method 2: System socket connection check to find local route
    chosen_iface = None
    local_ip = None
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        s.settimeout(0.5)
        s.connect(("8.8.8.8", 53))
        local_ip = s.getsockname()[0]
        s.close()
    except Exception:
        pass

    if local_ip:
        # Match local_ip to interface
        for name, addrs in psutil.net_if_addrs().items():
            for addr in addrs:
                if addr.family == socket.AF_INET and addr.address == local_ip:
                    chosen_iface = name
                    break
            if chosen_iface:
                break

    # Method 3: OS command fallback for gateway
    gateway = None
    if is_windows():
        try:
            output = subprocess.check_output("netsh interface ip show config", shell=True, text=True, stderr=subprocess.DEVNULL)
            for line in output.splitlines():
                if "Default Gateway" in line or "기본 게이트웨이" in line or "デフォルト ゲートウェイ" in line:
                    parts = line.split(":")
                    if len(parts) >= 2:
                        gw = parts[1].strip()
                        if gw and gw != "0.0.0.0":
                            gateway = gw
                            break
        except Exception:
            pass
    elif is_linux():
        try:
            with open("/proc/net/route") as f:
                for line in f.readlines()[1:]:
                    fields = line.strip().split()
                    if fields[1] == "00000000":
                        # Destination is 0.0.0.0 (default)
                        gw_hex = fields[2]
                        gateway = socket.inet_ntoa(bytes.fromhex(gw_hex)[::-1])
                        if not chosen_iface:
                            chosen_iface = fields[0]
                        break
        except Exception:
            pass

    return gateway, chosen_iface


def get_dns_servers() -> List[str]:
    """Retrieve active system DNS servers."""
    servers: List[str] = []

    # Try Scapy conf nameservers
    try:
        from scapy.all import conf
        for ns in conf.nameservers:
            if ns and ns not in servers and ns != "0.0.0.0":
                servers.append(str(ns))
    except Exception:
        pass

    if servers:
        return servers

    if is_linux() or is_macos():
        try:
            with open("/etc/resolv.conf", "r") as f:
                for line in f:
                    line = line.strip()
                    if line.startswith("nameserver"):
                        parts = line.split()
                        if len(parts) >= 2 and parts[1] not in servers:
                            servers.append(parts[1])
        except Exception:
            pass
    elif is_windows():
        try:
            output = subprocess.check_output("ipconfig /all", shell=True, text=True, stderr=subprocess.DEVNULL)
            for line in output.splitlines():
                if "DNS Servers" in line or "DNS 서버" in line:
                    parts = line.split(":")
                    if len(parts) >= 2:
                        ip = parts[1].strip()
                        if ip and ip not in servers and not ip.startswith("fe80"):
                            servers.append(ip)
        except Exception:
            pass

    return servers


def get_all_interfaces() -> List[NetworkInterface]:
    """Retrieve full details of all system network interfaces."""
    addrs = psutil.net_if_addrs()
    stats = psutil.net_if_stats()
    io_counters = psutil.net_io_counters(pernic=True)

    results: List[NetworkInterface] = []

    for name, addr_list in addrs.items():
        ip = None
        netmask = None
        broadcast = None
        mac = None

        for a in addr_list:
            # IPv4
            if a.family == socket.AF_INET:
                ip = a.address
                netmask = a.netmask
                broadcast = a.broadcast
            # MAC Address
            elif (
                (hasattr(psutil, "AF_LINK") and a.family == psutil.AF_LINK)
                or (is_windows() and getattr(a, "family", None) == -1)
                or ("link" in str(getattr(a, "family", "")).lower())
            ):
                if a.address and len(a.address) in (12, 17):
                    mac = a.address

        st = stats.get(name)
        is_up = st.isup if st else False
        speed = st.speed if st else 0
        mtu = st.mtu if st else 1500

        io = io_counters.get(name)
        rx_b = io.bytes_recv if io else 0
        tx_b = io.bytes_sent if io else 0
        rx_p = io.packets_recv if io else 0
        tx_p = io.packets_sent if io else 0

        results.append(
            NetworkInterface(
                name=name,
                ip=ip,
                netmask=netmask,
                broadcast=broadcast,
                mac=mac,
                is_up=is_up,
                speed_mbps=speed,
                mtu=mtu,
                rx_bytes=rx_b,
                tx_bytes=tx_b,
                rx_packets=rx_p,
                tx_packets=tx_p,
            )
        )

    # Sort UP interfaces with IPs first
    results.sort(key=lambda x: (not x.is_up, x.ip is None, x.name))
    return results


def get_primary_interface() -> Optional[NetworkInterface]:
    """Get the primary active network interface connected to the network."""
    interfaces = get_all_interfaces()
    gateway, gw_iface = get_default_gateway_and_interface()

    # Try matching gw_iface
    if gw_iface:
        for iface in interfaces:
            if iface.name == gw_iface or (iface.ip and gw_iface == iface.ip):
                return iface

    # Otherwise find first UP interface with non-loopback IPv4
    for iface in interfaces:
        if iface.is_up and iface.ip and not iface.ip.startswith("127."):
            return iface

    return interfaces[0] if interfaces else None

def normalize_mac(mac: str) -> str:
    """Normalize MAC address string into uppercase colon-delimited format."""
    clean = re.sub(r"[^0-9A-Fa-f]", "", mac).upper()
    if len(clean) == 12:
        return ":".join(clean[i : i + 2] for i in range(0, 12, 2))
    return mac.upper()


def lookup_vendor(mac: str) -> str:
    """Resolve vendor from MAC address using OUI prefix matching."""
    if not mac or mac in ["Unknown", "00:00:00:00:00:00", "FF:FF:FF:FF:FF:FF"]:
        return "Unknown"

    norm = normalize_mac(mac)
    prefix = norm[:8]  # First 3 octets "XX:XX:XX"

    if prefix in OUI_DATABASE:
        return OUI_DATABASE[prefix]

    # Check for locally administered address (MAC randomization)
    first_byte_hex = norm[:2]
    try:
        first_byte = int(first_byte_hex, 16)
        if first_byte & 0x02:
            return "Randomized / Private MAC"
    except ValueError:
        pass

def calculate_subnet(ip: str, netmask: Optional[str]) -> ipaddress.IPv4Network:
    """Calculate IPv4 network from IP and netmask, capped at /24 for safe local scanning."""
    if not netmask or netmask in ["0.0.0.0", "255.255.255.255"]:
        netmask = "255.255.255.0"
    try:
        network = ipaddress.IPv4Network(f"{ip}/{netmask}", strict=False)
        # Prevent accidentally scanning large /8 or /16 networks by bounding to /24
        if network.prefixlen < 24:
            ip_obj = ipaddress.IPv4Address(ip)
            c_block = f"{ip_obj.exploded.rsplit('.', 1)[0]}.0/24"
            return ipaddress.IPv4Network(c_block, strict=False)
        return network
    except Exception:
        ip_parts = ip.split(".")
        return ipaddress.IPv4Network(f"{ip_parts[0]}.{ip_parts[1]}.{ip_parts[2]}.0/24", strict=False)


def parse_arp_table() -> Dict[str, str]:
    """Parse operating system ARP table into {ip: mac} dictionary."""
    arp_entries: Dict[str, str] = {}
    try:
        if is_windows():
            output = subprocess.check_output("arp -a", shell=True, text=True, stderr=subprocess.DEVNULL)
            # Lines like: 192.168.1.1   00-11-22-33-44-55   dynamic
            pattern = re.compile(r"([0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3})\s+([0-9a-fA-F\-]{17})\s+([a-zA-Z]+)")
            for match in pattern.finditer(output):
                ip_str = match.group(1)
                mac_str = match.group(2).replace("-", ":")
                entry_type = match.group(3).lower()
                if not ip_str.endswith(".255") and not ip_str.startswith("224.") and entry_type != "invalid":
                    arp_entries[ip_str] = normalize_mac(mac_str)
        else:
            # Linux / macOS
            try:
                output = subprocess.check_output("arp -an", shell=True, text=True, stderr=subprocess.DEVNULL)
                pattern = re.compile(r"\(([0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3})\)\s+at\s+([0-9a-fA-F:]{17})")
                for match in pattern.finditer(output):
                    ip_str = match.group(1)
                    mac_str = match.group(2)
                    arp_entries[ip_str] = normalize_mac(mac_str)
            except Exception:
                pass
    except Exception as e:
        logger.debug(f"Failed to read system ARP table: {e}")

    return arp_entries


async def resolve_hostname(ip: str) -> Optional[str]:
    """Asynchronously perform reverse DNS lookup for an IP address."""
    loop = asyncio.get_running_loop()
    try:
        name_info = await loop.run_in_executor(None, socket.getnameinfo, (ip, 0), socket.NI_NAMEREQD)
        host = name_info[0]
        if host and host != ip:
            return host
    except Exception:
        pass

    try:
        host, _, _ = await loop.run_in_executor(None, socket.gethostbyaddr, ip)
        if host and host != ip:
            return host
    except Exception:
        pass

    return None


async def probe_host_tcp(ip: str, port: int = 80, timeout: float = 0.3) -> bool:
    """Send a quick non-intrusive TCP connection check to trigger host ARP entry."""
    try:
        _, writer = await asyncio.wait_for(asyncio.open_connection(ip, port), timeout=timeout)
        writer.close()
        await writer.wait_closed()
        return True
    except (asyncio.TimeoutError, ConnectionRefusedError, OSError):
        return False


async def sweep_subnet(network: ipaddress.IPv4Network, concurrency: int = 64) -> None:
    """Concurrently probe hosts on the subnet to update local ARP cache."""
    hosts = [str(h) for h in network.hosts()]
    semaphore = asyncio.Semaphore(concurrency)

    async def _worker(ip: str):
        async with semaphore:
            # Check common service ports
            for p in (80, 443, 22, 135, 445):
                if await probe_host_tcp(ip, port=p, timeout=0.2):
                    break

    await asyncio.gather(*[_worker(h) for h in hosts], return_exceptions=True)


def scan_scapy_arp(network_cidr: str, iface: Optional[str] = None, timeout: float = 1.5) -> Dict[str, str]:
    """Execute Scapy ARP broadcast ping if supported and permitted."""
    results: Dict[str, str] = {}
    try:
        from scapy.all import ARP, Ether, srp
        kwargs = {"timeout": timeout, "verbose": 0}
        if iface:
            kwargs["iface"] = iface

        pkt = Ether(dst="ff:ff:ff:ff:ff:ff") / ARP(pdst=network_cidr)
        ans, _ = srp(pkt, **kwargs)
        for _, rcv in ans:
            ip = rcv.psrc
            mac = normalize_mac(rcv.hwsrc)
            results[ip] = mac
    except Exception as e:
        logger.debug(f"Scapy ARP scan not possible or unprivileged: {e}")

    return results

async def grab_service_banner(reader: asyncio.StreamReader, writer: asyncio.StreamWriter, port: int) -> Optional[str]:
    """Safely and passively probe service banner without destructive payloads."""
    try:
        if port in (80, 8080, 8000, 8443):
            # Send standard benign HTTP HEAD request
            writer.write(b"HEAD / HTTP/1.0\r\nUser-Agent: COWMAN-Auditor/1.0\r\n\r\n")
            await writer.drain()
            data = await asyncio.wait_for(reader.read(512), timeout=0.8)
            text = data.decode("utf-8", errors="ignore")
            for line in text.splitlines():
                if line.lower().startswith("server:"):
                    return line.split(":", 1)[1].strip()
            if text:
                return text.splitlines()[0][:60].strip()

        data = await asyncio.wait_for(reader.read(256), timeout=0.8)
        text = data.decode("utf-8", errors="ignore").strip()
        if text:

            clean = " ".join(text.splitlines())[:80].strip()
            return clean
    except Exception:
        pass
    return None

        return None

    """Monitors live RX/TX rates, packet counts, protocol distribution, and active connections."""

    def __init__(self, interface: Optional[str] = None, interval: float = 1.0):

        self.interface_name = interface or self.config.general.interface

        if not self.interface_name:
            primary = get_primary_interface()
            if primary:
                self.interface_name = primary.name

        self._last_time = time.perf_counter()
        self._last_counters = self._get_interface_io()

    def _get_interface_io(self):
        """Retrieve IO counters for target interface or aggregate if none specified."""
        pernic = psutil.net_io_counters(pernic=True)
        if self.interface_name and self.interface_name in pernic:
            return pernic[self.interface_name]
        return psutil.net_io_counters()

    def sample(self) -> TrafficSnapshot:
        """Sample network statistics and compute transfer rates over the elapsed interval."""
        now_perf = time.perf_counter()
        dt = max(now_perf - self._last_time, 0.001)
        current_io = self._get_interface_io()

        rx_bytes = current_io.bytes_recv - self._last_counters.bytes_recv
        tx_bytes = current_io.bytes_sent - self._last_counters.bytes_sent
        rx_pkts = current_io.packets_recv - self._last_counters.packets_recv
        tx_pkts = current_io.packets_sent - self._last_counters.packets_sent

        # Protect against counter resets / interface restarts
        if rx_bytes < 0:
            rx_bytes = 0
        if tx_bytes < 0:
            tx_bytes = 0
        if rx_pkts < 0:
            rx_pkts = 0
        if tx_pkts < 0:
            tx_pkts = 0

        rx_rate_kbs = round((rx_bytes / 1024.0) / dt, 2)
        tx_rate_kbs = round((tx_bytes / 1024.0) / dt, 2)
        rx_packets_sec = round(rx_pkts / dt, 1)
        tx_packets_sec = round(tx_pkts / dt, 1)

        self._last_time = now_perf
        self._last_counters = current_io

        # Collect active connections
        active_conns: List[ActiveConnectionInfo] = []
        tcp_count = 0
        udp_count = 0

        try:
            raw_conns = psutil.net_connections(kind="inet")
            for c in raw_conns:
                proto = "TCP" if c.type == psutil.SOCK_STREAM else "UDP"
                if proto == "TCP":
                    tcp_count += 1
                else:
                    udp_count += 1

                laddr = f"{c.laddr.ip}:{c.laddr.port}" if c.laddr else "-"
                raddr = f"{c.raddr.ip}:{c.raddr.port}" if c.raddr else "-"

                        remote_address=raddr,

                        process_name=pname,
                    )
                )

            logger.debug("Access denied when reading system socket tables.")
        except Exception as e:
            logger.debug(f"Error inspecting network connections: {e}")

            interface=self.interface_name or "All",
            rx_rate_kbs=rx_rate_kbs,
            tx_rate_kbs=tx_rate_kbs,

            tx_packets_sec=tx_packets_sec,

            tcp_count=tcp_count,
            udp_count=udp_count,

def calculate_entropy(text: str) -> float:
    """Calculate Shannon entropy for string randomness detection (DGA indicator)."""
    if not text:
        return 0.0
    text = text.lower()
    freq = {}
    for c in text:
        freq[c] = freq.get(c, 0) + 1
    length = len(text)
    entropy = 0.0
    for count in freq.values():
        p = count / length
        entropy -= p * math.log2(p)
    return round(entropy, 3)


def inspect_dns_anomaly(query_name: str, config=None) -> tuple[bool, Optional[str]]:
    """Evaluate whether a DNS query matches known anomaly patterns."""
    cfg = config or get_config()
    clean_domain = query_name.rstrip(".")

    # High length check (indicative of DNS tunneling or data exfiltration)
    if len(clean_domain) > cfg.dns.domain_length_alert_threshold:
        return True, f"Excessive domain length ({len(clean_domain)} chars) - potential DNS tunnel"

    # Entropy check for base domain labels
    labels = clean_domain.split(".")
    for label in labels:
        if len(label) > 10:
            ent = calculate_entropy(label)
            if ent > cfg.dns.entropy_alert_threshold:
                return True, f"High Shannon entropy ({ent:.2f}) on label '{label}' - potential DGA"

    # Suspicious hex or base64 encoded subdomain
    if len(labels) > 0 and len(labels[0]) > 20:
        if all(c in "0123456789abcdef" for c in labels[0].lower()):
            return True, "Hex-encoded subdomain prefix - potential tunneling"

    return False, None


class DnsMonitor:
    """Captures and analyzes DNS network traffic."""

    def __init__(self, interface: Optional[str] = None):
        self.config = get_config()
        self.interface_name = interface or self.config.general.interface
        self._packet_queue: queue.Queue = queue.Queue(maxsize=self.config.dns.buffer_size)
        self._stop_event = threading.Event()
        self._sniffer_thread: Optional[threading.Thread] = None

    def _process_packet(self, pkt):
        try:
            if pkt.haslayer(scapy.DNS) and pkt.getlayer(scapy.DNS).qr == 0:  # qr == 0 is DNS Query
                dns_layer = pkt.getlayer(scapy.DNS)
                if dns_layer.qd is None:
                    return

                qname = dns_layer.qd.qname.decode("utf-8", errors="ignore").rstrip(".")
                qtype_code = dns_layer.qd.qtype
                qtype_str = DNS_QTYPE_MAP.get(qtype_code, str(qtype_code))

                src_ip = "Unknown"
                dst_ip = "Unknown"

                if pkt.haslayer(scapy.IP):
                    src_ip = pkt[scapy.IP].src
                    dst_ip = pkt[scapy.IP].dst
                elif pkt.haslayer(scapy.IPv6):
                    src_ip = pkt[scapy.IPv6].src
                    dst_ip = pkt[scapy.IPv6].dst

                is_anomaly, reason = inspect_dns_anomaly(qname, self.config)

                event = DnsQueryEvent(
                    timestamp=utc_now(),
                    source_ip=src_ip,
                    destination_ip=dst_ip,
                    query_name=qname,
                    query_type=qtype_str,
                    is_anomalous=is_anomaly,
                    anomaly_reason=reason,
                )

                # Persist to database
                DnsLogRepository.log(event)

                try:
                    self._packet_queue.put_nowait(event)
                except queue.Full:
                    try:
                        self._packet_queue.get_nowait()
                        self._packet_queue.put_nowait(event)
                    except Exception:
                        pass
        except Exception as e:
            logger.debug(f"Error parsing DNS packet: {e}")

    def _sniff_worker(self):
        kwargs = {
            "filter": "udp port 53 or tcp port 53",
            "prn": self._process_packet,
            "store": 0,
            "stop_filter": lambda _: self._stop_event.is_set(),
        }
        if self.interface_name:
            kwargs["iface"] = self.interface_name

        try:
            scapy.sniff(**kwargs)
        except Exception as e:
            logger.warning(f"DNS sniffer stopped: {e}")

    def start(self) -> bool:
        """Start sniffer background thread. Returns False if unprivileged."""
        self._stop_event.clear()
        self._sniffer_thread = threading.Thread(target=self._sniff_worker, daemon=True)
        self._sniffer_thread.start()
        return True

    def stop(self):
        """Stop sniffer thread."""
        self._stop_event.set()
        if self._sniffer_thread and self._sniffer_thread.is_alive():
            self._sniffer_thread.join(timeout=1.0)

    def get_events(self, timeout: float = 0.5) -> List[DnsQueryEvent]:
        """Drain buffered events from sniffer queue."""
        events: List[DnsQueryEvent] = []
        try:
            while not self._packet_queue.empty():
                events.append(self._packet_queue.get_nowait())
        except Exception:
            pass
        return events

    name: str = "New Device Discovered"
    category: str = "DISCOVERY"

                    description=desc,
                    details={
                        "ip": device.ip,
                        "mac": device.mac,
                        "vendor": device.vendor,
                        "hostname": device.hostname,
                    },
                )
            )

class SecurityEventEngine:
    """Central engine managing defensive security detection rules."""

    def __init__(self):
        self.rules: List[BaseSecurityRule] = [
            NewDeviceRule(),
            DeviceStateChangeRule(),
            UnexpectedServiceRule(),
            InterfaceStateRule(),
            DnsAnomalyRule(),
            NetworkAnomalyRule(),
        ]
        self._listeners: List[Callable[[SecurityEvent], None]] = []

    def register_rule(self, rule: BaseSecurityRule) -> None:
        """Add a custom detection rule to the engine."""
        self.rules.append(rule)

    def subscribe(self, callback: Callable[[SecurityEvent], None]) -> None:
        """Register a callback for newly triggered security events."""
        self._listeners.append(callback)

    def evaluate(self, context: Dict[str, Any]) -> List[SecurityEvent]:
        """Run all active rules against the telemetry context, saving events to DB."""
        new_events: List[SecurityEvent] = []

        for rule in self.rules:
            try:
                matched = rule.evaluate(context)
                for event in matched:
                    # Persist event to database
                    saved_event = SecurityEventRepository.add(event)
                    new_events.append(saved_event)
                    logger.info(f"[{event.severity.value}] {event.title}: {event.description}")
                    # Notify registered listeners
                    for listener in self._listeners:
                        try:
                            listener(saved_event)
                        except Exception as e:
                            logger.debug(f"Error in event listener: {e}")
            except Exception as e:
                logger.error(f"Rule evaluation failed for {rule.rule_id}: {e}")

        return new_events

    def process_device_discovery(self, device: Device, is_new: bool = False, old_status: Optional[str] = None) -> List[SecurityEvent]:
        """Convenience method to evaluate device discovery telemetry."""
        ctx = {
            "device": device,
            "is_new_device": is_new,
            "old_status": old_status,
            "new_status": device.status,
        }
        return self.evaluate(ctx)

    def process_port_scan(self, report: PortScanReport) -> List[SecurityEvent]:
        """Convenience method to evaluate port scan results."""
        return self.evaluate({"port_scan_report": report})

    def process_dns_event(self, dns_event: DnsQueryEvent) -> List[SecurityEvent]:
        """Convenience method to evaluate a DNS query event."""
        return self.evaluate({"dns_event": dns_event})

    def process_traffic_snapshot(self, snapshot: TrafficSnapshot) -> List[SecurityEvent]:
        """Convenience method to evaluate traffic telemetry."""
        return self.evaluate({"traffic_snapshot": snapshot})

def get_engine(db_path: Optional[Path] = None):
    global _ENGINE, _SESSION_FACTORY
    if _ENGINE is None or db_path is not None:
        target_path = db_path or get_config().resolved_database_path()

def get_db_session() -> Generator[Session, None, None]:
    """Provide a transactional database session."""
    factory = get_session_factory()
    session: Session = factory()
    try:
        yield session
        session.commit()
    except Exception:
        session.rollback()
        raise
    finally:
        session.close()

class DeviceRepository:
    """Manages persistent device inventory."""

    @staticmethod
    def _model_to_domain(m: DeviceModel) -> Device:
        return Device(
            ip=m.ip,
            mac=m.mac,
            hostname=m.hostname,
            vendor=m.vendor,
            status=m.status,
            device_type=m.device_type,
            first_seen=m.first_seen if m.first_seen.tzinfo else m.first_seen.replace(tzinfo=timezone.utc),
            last_seen=m.last_seen if m.last_seen.tzinfo else m.last_seen.replace(tzinfo=timezone.utc),
            open_ports=m.open_ports,
            metadata=m.metadata_dict,
        )

    @classmethod
    def save_or_update(cls, device: Device, session: Optional[Session] = None) -> Device:
        """Upsert a discovered device."""
        def _execute(s: Session) -> Device:
            existing = s.query(DeviceModel).filter(DeviceModel.ip == device.ip).first()
            now = utc_now()
            if existing:
                if device.mac and device.mac != "Unknown":
                    existing.mac = device.mac
                if device.hostname:
                    existing.hostname = device.hostname
                if device.vendor and device.vendor != "Unknown":
                    existing.vendor = device.vendor
                if device.device_type and device.device_type != "Unknown":
                    existing.device_type = device.device_type
                existing.status = device.status
                existing.last_seen = now
                if device.open_ports:
                    merged_ports = sorted(list(set(existing.open_ports + device.open_ports)))
                    existing.open_ports = merged_ports
                meta = existing.metadata_dict
                meta.update(device.metadata)
                existing.metadata_dict = meta
                s.flush()
                return cls._model_to_domain(existing)
            else:
                new_model = DeviceModel(
                    ip=device.ip,
                    mac=device.mac or "Unknown",
                    hostname=device.hostname,
                    vendor=device.vendor or "Unknown",
                    status=device.status or "ONLINE",
                    device_type=device.device_type or "Unknown",
                    first_seen=device.first_seen or now,
                    last_seen=device.last_seen or now,
                    open_ports=device.open_ports or [],
                    metadata_dict=device.metadata or {},
                )
                s.add(new_model)
                s.flush()
                return cls._model_to_domain(new_model)

        if session:
            return _execute(session)
        with get_db_session() as s:
            return _execute(s)

from datetime import datetime, timedelta, timezone
import re

def parse_datetime_flexible(value: Optional[str]) -> Optional[datetime]:
    """Parse a date/time string, ISO timestamp, or relative time offset (e.g. '1h', '30m', '1d')."""
    if not value or not value.strip():
        return None

    val = value.strip().lower()
    now = datetime.now(timezone.utc)

    # Relative offset: e.g. "15m", "2h", "1d", "7d", "30s"
    rel_match = re.match(r"^(\d+)\s*(s|sec|m|min|h|hr|d|day|w|week)s?$", val)
    if rel_match:
        amount = int(rel_match.group(1))
        unit = rel_match.group(2)
        if unit.startswith("s"):
            return now - timedelta(seconds=amount)
        elif unit.startswith("m"):
            return now - timedelta(minutes=amount)
        elif unit.startswith("h"):
            return now - timedelta(hours=amount)
        elif unit.startswith("d"):
            return now - timedelta(days=amount)
        elif unit.startswith("w"):
            return now - timedelta(weeks=amount)

    if val == "today":
        return now.replace(hour=0, minute=0, second=0, microsecond=0)
    elif val == "yesterday":
        yesterday = now - timedelta(days=1)
        return yesterday.replace(hour=0, minute=0, second=0, microsecond=0)

    # Try common formats
    formats = [
        "%Y-%m-%dT%H:%M:%S%z",
        "%Y-%m-%dT%H:%M:%S",
        "%Y-%m-%d %H:%M:%S",
        "%Y-%m-%d %H:%M",
        "%Y-%m-%d",
        "%H:%M:%S",
        "%H:%M",
    ]

    for fmt in formats:
        try:
            parsed = datetime.strptime(value.strip(), fmt)
            if fmt in ["%H:%M:%S", "%H:%M"]:
                # Combine with today's date
                parsed = now.replace(
                    hour=parsed.hour,
                    minute=parsed.minute,
                    second=parsed.second,
                    microsecond=0,
                )
            if parsed.tzinfo is None:
                parsed = parsed.replace(tzinfo=timezone.utc)
            return parsed
        except ValueError:
            continue

    raise ValueError(f"Unable to parse timestamp or relative time '{value}'. Examples: '1h', '30m', '2026-09-30 14:00'.")


def format_timestamp(dt: Optional[datetime] = None, include_date: bool = True) -> str:
    """Format datetime cleanly for terminal display. Defaults to current time if None."""
    if dt is None:
        dt = datetime.now(timezone.utc)
    local_dt = dt.astimezone() if dt.tzinfo else dt
    if include_date:
        return local_dt.strftime("%Y-%m-%d %H:%M:%S")
    return local_dt.strftime("%H:%M:%S")


def format_duration(seconds: float) -> str:
    """Format duration in seconds to human-readable string."""
    if seconds < 1.0:
        return f"{seconds * 1000:.1f}ms"
    elif seconds < 60:
        return f"{seconds:.2f}s"
    elif seconds < 3600:
        mins = int(seconds // 60)
        secs = int(seconds % 60)
        return f"{mins}m {secs}s"
    else:
        hours = int(seconds // 3600)
        mins = int((seconds % 3600) // 60)
        return f"{hours}h {mins}m"
